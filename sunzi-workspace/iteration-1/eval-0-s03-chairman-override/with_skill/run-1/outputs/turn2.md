這讓我修正剛才的判斷. 我引了 "不知三軍之事", 暗示董事長是從後方插手前線. 但前十大客戶的關係和價格都在他手上, 對這些客戶來說, 他就是前線, 業務反而是後到的那一方.

所以問題換了. 不是董事長越權, 而是組織圖上寫著業務負責這些客戶, 實際上談判桌不在業務那裡. 業務拿著一個沒有實權的位置, 被夾在中間, 當然不知道該聽誰的.

兵勢第五 (5.6) 說 "求之於勢, 不責於人". 這時候去要求業務更有擔當, 或去要求董事長別打電話, 都是在責人. 勢的問題是: 這十個客戶, 到底算誰的.

不過這個事實能說明的只到前十大. 如果他改的報價也落在前十大以外的客戶, 那就是另一件事了.

一個業務若只是在傳遞別人談好的價格, 他在客戶眼裡累積的不是信任, 是 "等一下我再問問上面".
